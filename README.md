# cnweb-k8-lab

## 项目简介

本项目是一个用于归档、整理和发布多个独立 HTML 页面的仓库。仓库本身不针对任何特定域名或网站，仅作为静态 HTML 资源的集合容器，方便统一管理、版本控制与分发。

## 目录说明

```
.
├── pages/          # 存放各独立 HTML 页面（按功能或场景分类）
├── assets/         # 公共资源文件（如 CSS、JavaScript、图片等）
├── docs/           # 项目文档或使用说明（可选）
└── README.md       # 本文件
```

- `pages/` 目录下每个子文件夹或文件代表一个独立的页面单元，彼此间无依赖关系。
- `assets/` 中的资源供 `pages/` 下的页面引用，可提升复用性。
- 如有额外说明文档，可放入 `docs/` 目录。

## 页面归档说明

- 所有归档页面均为独立 HTML 文件，可直接在浏览器中打开使用。
- 页面内容遵循通用 Web 标准，不依赖特定后端服务。
- 归档范围包括但不限于：工具页面、信息展示页、实验性原型等。
- 每个页面内部应包含必要的说明或注释，以便于理解其用途。

## 维护说明

- 欢迎提交 Pull Request 添加新的独立页面，或改进现有页面。
- 新增页面请放入 `pages/` 下适当的子目录，或新建目录以保持结构清晰。
- 请确保页面不包含任何指向具体域名、网站或带有营销性质的链接与内容。
- 提交前请检查页面是否在本地正常渲染，并移除调试代码。
- 对于过时或不再维护的页面，可在 Issue 中讨论后进行移除或归档处理。
